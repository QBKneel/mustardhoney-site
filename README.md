# MustardHoney — coming soon page

Static one-page site (plain HTML/CSS/JS, no build step) published with GitHub Pages from the `main` branch root.

- **Links / email:** edit `assets/js/config.js` only (contact email, mailto subject lines, optional Instagram).
- **Logo & product photos:** replace the dashed placeholder boxes in `index.html` (search for `PLACEHOLDER`).
- All asset paths are relative, so the site works at `https://<user>.github.io/mustardhoney-site/` and on a custom domain.
